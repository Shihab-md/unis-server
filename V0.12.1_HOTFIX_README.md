# UNIS Server V0.12.1 — Authorization Hotfix

## Root cause
Server V0.11 replaced `middleware/authorizationMiddleware.js` and accidentally omitted the V0.10 Inspection / Reports / Accounts authorization exports. V0.12 did not modify that middleware, so routes such as `routes/report.js`, `routes/inspectionReportRoutes.js`, and `routes/feesRoutes.js` could import helpers that no longer existed.

## Fix
Replace only:

`middleware/authorizationMiddleware.js`

The corrected file contains both:
- V0.10 Inspection / Reports / Accounts authorization helpers; and
- V0.11 Administration / Niswan / Muavin authorization helpers.

No controller, route, model, database schema, package, or environment change is included.

## Validation
- All authorization helper imports across the reconstructed current server resolve to exports.
- All 92 JavaScript source files pass `node --check`.

## Apply
From server root, back up the existing middleware file, then overlay this hotfix and restart nodemon / Node.
